Sports Activity Tracker

A web-based Sports Activity Tracker built using Node.js, Express.js and EJS. This project provides a foundation for developing a web application focused on tracking and managing sports activities.

About the Project

The Sports Activity Tracker is designed to serve as a platform for managing sports-related activities through a web interface.

The application uses Express.js to run the server and EJS as its view template engine, allowing dynamic web pages to be developed and rendered.

Technologies Used
Node.js – JavaScript runtime environment.
Express.js – Web application framework for Node.js.
EJS – Embedded JavaScript templating engine.
HTML/CSS – For structuring and styling web pages.
JavaScript – For application logic and interactivity.

Installation and Setup

Follow these steps to run the project locally.

1. Clone the Repository
bash
git clone https://github.com/AhmadRPStudent/Sports-Activity-Tracker.git

2. Navigate to the Project Folder
bash
cd Sports-Activity-Tracker

3. Install Dependencies
bash
npm install

4. Start the Application
bash
node app.js

5. Open in Browser

Visit the following URL:

text
http://localhost:3000
